# Milestone 03 Submission Checklist

## Dropbox ZIP Contents

Use one ZIP named in the instructor format:

```text
LastName_FirstName_ID__M3.zip
```

Include:
- milestone report PDF(s)
- `links.txt`
- final demo video file or video link
- presentation PDF or one-page visual overview PDF

## Recommended Files to Export / Include

- Testing summary PDF from `docs/milestone-03/testing-summary-report.md`
- Presentation PDF from `docs/milestone-03/presentation-one-pager.md`
- Demo notes from `docs/milestone-03/final-demo-outline.md`

## `links.txt` Contents

- GitHub repository link
- GitHub Project board link
- Wiki/docs link
- demo video link if video is hosted online

## Final Repo Checks

- server starts with `npm run start`
- `client/login.html` opens and both roles work
- `npm run verify` passes in `server/`
- README is updated
- Milestone 03 docs are present

## Manual Items To Capture Before Submission

- GitHub Projects final Kanban snapshot
- final activity blog/wiki reflection entry
- final demo video
- PDF exports of the report and presentation artifact
