OpenSlot

A university office-hours scheduling system that connects students, professors, server-side booking logic, and a relational database into one end-to-end workflow.

Student + Professor Roles Node.js + Express API SQLite Relational DB
Project Goal

Help students find, book, manage, and review office-hour appointments while allowing professors to create, publish, and maintain availability.

Core Data
users courses office_hour_slots appointments

Primary User Workflows

End-to-End Paths

Student Flow

  • Sign in using a demo student account
  • Browse available office-hour slots
  • Review and confirm booking with notes
  • View appointment details
  • Reschedule or cancel an upcoming booking

Professor Flow

  • Sign in using a demo professor account
  • Create future office-hour slots
  • Publish or cancel draft slots
  • View weekly schedule and upcoming sessions
  • Update public profile information
Milestone 3 upgrade: the app now uses a persistent SQLite database with server-side validation, protected routes, and an automated smoke test for core workflows.

Key Features

User-Facing Functionality

Booking System

Students can browse posted slots, confirm a session, and store booking notes.

Appointment Management

Upcoming appointments can be rescheduled or cancelled before the start time.

Professor Scheduling

Professors can create, review, publish, and cancel office-hour availability.

Profile Maintenance

Professor contact/location details can be updated through the settings screen.

Validation and Security

Basic Hygiene Implemented
All protected API routes require an auth token, and role checks enforce student-only and professor-only actions.
Server-side validation rejects invalid IDs, invalid status values, past-dated slot creation, and overlapping professor slots.
Current limitation: authentication is demo-token based and intended for course demonstration, not production deployment.
